# 金融ネットワーク分析用データセット
このレポジトリは「シミュレーテッド分岐マシンによる金融ネットワーク分析」で用いたインスタンス及びインスタンス生成用コードを格納しています。

## データセットの構造
`.zip`ファイルには各機関数Nに対応した問題インスタンスが.pkl形式で50個ずつ含まれています。`.pkl`ファイルにはpythonの辞書型のリストで問題インスタンスを収めました。

## データセットの生成
レポジトリ内にある`instances_generator.py`ファイルを実行させることで`.zip`ファイルに収納されている問題インスタンスを生成することが可能です。
