#Dataset for Financial Network Analysis
This repository contains the problem instances and the code used to generate them for the study Financial Network Analysis Using a Simulated Bifurcation Machine.

##Dataset Structure
Each `.zip` file contains 50 problem instances corresponding to a given number of financial institutions N. Each `.pkl` file stores a list of Python dictionaries, each representing a problem instance.

##Dataset Generation
The problem instances contained in the .zip files can be regenerated by running `instances_generator.py` included in this repository.
